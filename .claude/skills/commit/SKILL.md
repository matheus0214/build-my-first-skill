# Commit padrão

1. Rode `git diff --staged` e entenda a mudança.
2. Use Conventional Commits: `feat:`, `fix:`, `chore:`, `refactor:`
3. Título em inglês, atê 72 caracteres, no imperativo.
4. Nunca faça `git push` sem eu pedir
